# JOKAS Audio Bot

Telegram-бот с меню как на референсе:

- кнопочные меню в сообщениях;
- при переходе старое меню удаляется;
- заказы и оплата через менеджера;
- промокоды;
- редактируемые цены;
- поддержка в формате чата с администраторами;
- любой администратор может взять обращение;
- после взятия обращения сообщения пользователя идут назначенному админу и наоборот;
- главный администратор может закрывать обращения и управлять администраторами;
- SQLite, поэтому отдельная БД-сервер не нужна.

## Запуск

1. Установить Python 3.11+.
2. Создать бота через @BotFather и получить токен.
3. Скопировать `.env.example` в `.env`.
4. Заполнить `BOT_TOKEN` и `MAIN_ADMIN_ID`.
5. При необходимости указать дополнительные ID в `ADMIN_IDS` через запятую.
6. Установить зависимости:

```bash
pip install -r requirements.txt
```

7. Запустить:

```bash
python bot.py
```

База `bot.db` создастся автоматически.

## Как работает поддержка

Пользователь нажимает «Тех. Поддержка» и получает кнопку «Открыть обращение».
После открытия можно отправлять обычные сообщения, фото, документы и другие сообщения.

Все администраторы получают уведомление с кнопкой «Взять обращение».
Первый администратор, который нажал кнопку, становится ответственным.
После этого переписка идет напрямую через бота:

Пользователь -> назначенный администратор
Администратор -> пользователь

Другие администраторы больше не получают новые сообщения этого обращения.

Главный администратор видит расширенные кнопки управления и может закрыть обращение.

## Важно

Оплата здесь специально сделана через менеджера: бот не хранит данные банковских карт и не принимает номера карт пользователей.
